# 🌾 Jáchal Fumigación - Sitio Web Oficial

Sitio web institucional y de servicios para **Jáchal Fumigación**, emprendimiento especializado en control de plagas, desinsectación, desratización y tratamientos agrícolas en el Departamento de San José de Jáchal, San Juan.

---

## 🚀 Tecnologías Utilizadas

- **HTML5** (Semántico y optimizado para SEO local)
- **CSS3 / Bootstrap 5.3** (Diseño 100% Responsive)
- **Bootstrap Icons**
- **JavaScript ES6** (Integración asíncrona mediante Fetch API)
- **Formspree** (Procesamiento de formularios directo a correo)

---

## 🛠️ Servicios

- 🐜 **Desinsectación:** Erradicación de cucarachas, hormigas, chinches, pulgas, arañas y mosquitos.
- 🐀 **Desratización:** Control preventivo y correctivo de roedores.
- 🌿 **Fincas y Frutales:** Tratamiento de plagas agrícolas en parcelas y sectores rurales.

---

## 📍 Zona de Cobertura

San José de Jáchal, Huaco, Villa Mercedes, Pampa del Chañar, Otra Banda, Niquivil, San Roque y zonas aledañas.
